# HUDR2 Lessons (Self-Learning Log)

Append one entry per non-obvious finding or bugfix. Mirror durable findings in Engram (`project: "hudr2"`).
Format: `- YYYY-MM-DD · <area> · <symptom> → <cause> → <fix> (test: <test_name>)`

- 2026-11-02 · scripts · `attach-hudr2.cmd` and `hudr2.cmd` failed with syntax errors on Windows `cmd.exe` → Unix `LF` line endings broke multi-line `if (...)` variable parsing in `cmd.exe` → enforced `CRLF` on `*.cmd` and `*.bat` via `.gitattributes` and added native PowerShell `.ps1` launchers.
- 2026-11-05 · quotas · False critical alerts in `Integraciones` when secondary pools were exhausted while the active model pool was healthy → static worst-of-all-pools overwrote account health → implemented dynamic model-family health (`evaluate_account_for_model` in `src/quotas/cliproxy.rs`): `Integraciones` evaluates the pool matching the active session model (`Claude`, `GPT`, `DeepSeek`, `Qwen`, `Gemini`) and defaults to `Gemini` when no specific family is active, while `Cuota de Modelos` displays individual traffic-light colors for every pool (tests: `test_dynamic_model_family_quota_health_claude_gpt_deepseek_gemini`, `test_ui_integraciones_card_reflects_gemini_sovereignty_without_false_criticals`).
- 2026-11-06 · events · Idle CPU usage from 50ms terminal polling and unconditional `needs_redraw = true` → replaced blind loop with `mpsc::unbounded_channel`, 300ms debounced `notify` watcher, Herdr IPC subscription, and `PartialEq` check `state.snapshot != prev_snapshot` in `refresh_all` (test: `test_refresh_all_skips_redraw_when_snapshot_unchanged`).
- 2026-11-06 · mouse · Terminal flooded with mouse motion events whenever the cursor crossed the HUD pane → `crossterm::event::EnableMouseCapture` enables motion tracking (`?1002h`/`?1003h`) → replaced with raw `\x1b[?1000h\x1b[?1006h` (button clicks + scroll wheel only in SGR mode) and `TerminalGuard` drop cleanup in `src/main.rs`.
- 2026-11-06 · keyboard · Pressing `1`–`9` or `c` on Windows toggled cards twice (opening and immediately closing) → Crossterm `0.28` on Windows emits both `KeyEventKind::Press` and `KeyEventKind::Release` → filter `k.kind == KeyEventKind::Press` in `src/main.rs`.
- 2026-11-06 · herdr · Agent status updates were missed over Herdr NDJSON IPC → Herdr emits `pane.agent_status_changed` with a dot `.` while `pane_updated` and `pane_closed` use underscores `_` → `HerdrClient::parse_wire_event` normalizes both formats (test: `test_herdr_wire_event_parsing`).
- 2026-11-06 · git · HUD git queries collided with user/agent git operations and re-triggered `.git` file watchers → `git status` takes optional index locks by default → `run_git_cmd` sets `GIT_OPTIONAL_LOCKS=0`, runs at `git_root` with a 3s timeout, and reads `.git/HEAD` directly from disk without spawning a subprocess.
- 2026-11-06 · safety · Inline git diff preview on click could expose secrets if `.env` or key files were clicked → added `is_sensitive_file` in `src/git.rs` blocking `.env*`, `*secret*`, `*token*`, `*password*`, `*credential*`, `*.pem`, `*.key`, `id_rsa`, `id_ed25519`, etc. (test: `test_git_sensitive_file_protection_and_inline_diff_click`).
- 2026-11-06 · state · Persisting collapsed cards to disk in `AppState::new()` caused unit tests to share/pollute state via the user's home config file → kept `AppState::new()` pure in-memory (`config_path: None`) and added `AppState::with_config(path)` for `main.rs` (test: `test_collapsed_cards_atomic_persistence`).
- 2026-11-06 · pi · Context percentage differed from Pi/Gentle Shell runtime when `models-store.json` had stale limits → Pi registers runtime limits in `cpamc-models-cache.json` first → `resolve_pi_context_limit` checks `cpamc-models-cache.json` before `models-store.json` (test: `test_pi_jsonl_incremental_tail_and_context_cache`).
- 2026-11-06 · scripts · PowerShell 5.1 (`powershell.exe`) failed to parse `.ps1` files containing literal UTF-8 box-drawing chars (`╭│├╰`) when saved without BOM (byte `0x94` interpreted as Windows-1252 smart quote `”`) → keep `.ps1` source files pure ASCII and compare Unicode codepoints numerically (`0x256D`, `0x2502`, `0x251C`, `0x2570`) with `[Console]::OutputEncoding = [System.Text.Encoding]::UTF8`.
